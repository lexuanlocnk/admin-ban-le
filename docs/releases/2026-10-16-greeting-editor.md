# Greeting editor and website overlay alignment

The production website used a fixed counter position (76.03%, 48.24%) while Admin stored an editable position (currently 70%, 59%). The website release now applies the persisted layouts, visibility, colors and scale to all popup steps. Integer normalization/default coordinates and counter typography match the Admin editor. Wish/subtitle alignment respects the layout direction. The popup card uses the same 4:3 canvas and fits the viewport height.

Admin changes: align daily starting count and popup frequency controls; shorten image labels to “Hình ảnh” and floating-widget tooltip label to “Tiêu đề”; remove the decorative logo heading, redundant step headings and the three text fields shown in the request; remove the two hardcoded “use uploaded banner” shortcuts. Previously stored button/subtitle/result-title values remain in the save payload. Upload, URL, delete-image, positioning, wishes and event enable/disable behavior remain available. Save is outside both configuration columns and in normal flow at the form bottom.
